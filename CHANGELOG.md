# Changelog

## 0.1.0 (unreleased)

First packaged build.

### Features

- Two panels with tabs, locked tabs, brief, full and custom views, natural sorting, session restore
- Quick search and filter, history, hotlist, drive and mount menu
- Command line and embedded terminal with folder sync (bash, zsh, fish)
- Copy, move, rename, make folder, Trash and permanent delete, links, properties
- Background job queue with pause, resume and cancel; conflict handling
- Batch rename in an editor with preview and undo
- Viewer (text and hex, six encodings, search), quick view, external editor
- Find files (names, contents, size, date, inside archives) and result panels
- Read-only zip, tar and 7z archives, including encrypted zip and 7z
- Folder compare, user menu with per-folder menus
- Far, Total Commander and Midnight Commander key presets, all rebindable
- Far Blue, Commander Light and Adwaita themes with highlighting rules and icons
- Clipboard and drag and drop with GNOME Files
- Debian package, desktop entry, AppStream data, man page
- `ofm --version`, `--help`, `--dump-keys`
